# Lab06 - Reusable Interaction System

In this lab I created a simple pressure plate collider system and mover actor component. The pressure plate sends
an event that triggers a boolean change in the mover enabling it. The mover has functionality for movement and
rotation. 

I added two independent extensions: first is that the pressure plates are hold-to-activate, meaning that they will only work while you're standing on them. Second is that the mover component attached to the objects has 
rotation as well as translation functionality.
